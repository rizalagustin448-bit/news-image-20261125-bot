## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024×1024, PNG) to `$MAKEFUN_OUTPUT_DIR/entry.png`. Running it twice writes identical bytes. The image was drawn with Pillow + DejaVu fonts from the verified story set — no invented numbers, no hype, no speculation shown as fact.
